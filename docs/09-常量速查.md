## 4. 键值 ⚠️⚠️（最高危区）

`mr_event(MR_KEY_*, key, 0)` 里的 `key`。**枚举顺序反直觉，必须死记这张表**：

| 值 | 键 | 值 | 键 |
|---|---|---|---|
| 0–9 | 数字键 `0`–`9` | 15 | 右 |
| 10 | `*` | **16** | **挂机键 POWER** ⚠️ |
| 11 | `#` | 17 | 左软键 |
| 12 | 上 | 18 | 右软键 |
| 13 | 下 | 19 | 接听键 SEND |
| 14 | 左 | **20** | **确认键 SELECT** ⚠️ |
| 21 | 侧键上 VOLUME_UP | 22 | 侧键下 VOLUME_DOWN |
| 23 | 清除键 CLEAR | | |

> ⚠️ 确认键是 **20**。把 16 当确认 = 每次按确定都在挂机。

## 6. 内存布局（硬约定）

| 项 | 值 |
|---|---|
| 代码段 / 表基址 | `0x00080000`，1 MB |
| 栈 | `0x00180000`，1 MB |

## 7. 声音

### `mr_playSound` 的 type ⚠️（两版枚举冲突）

| 值 | 老版（5 值） | vmrp 版（7 值） |
|---|---|---|
| 0 | MIDI | MIDI |
| 1 | WAV | WAV |
| 2 | MP3 | MP3 |
| 3 | **AMR** | **PCM** |
| 4 | **PCM** | **M4A** |
| 5 / 6 | — | AMR / AMR_WB |

用数据魔数消歧：`RIFF`=WAV、`MThd`=MIDI、`#!AMR\n`=AMR（**5 字节**）。

### `T_MEDIA_TYPE`（`mr_platEx(201x~216x)` 的 x）

`1`=MIDI `2`=WAVE `3`=MP3 `4`=AMR `5`=PCM `6`=M4A `7`=AAC

### 播放状态（`209x` 返回 `1000 + 值`）

| 值 | 状态 |
|---|---|
| 1001 | IDLE |
| 1002 | INITED |
| 1003 | LOADED |
| 1004 | PLAYING |
| 1005 | PAUSED |
| 1006 | SUSPENDED |
| 1007 | SUSPENDING |
