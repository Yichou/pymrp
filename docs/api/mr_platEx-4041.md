# mr_platEx(4041) - 创建平台电话本浏览对象

```c
int32 mr_platEx (int32 code = 4041, uint8* input, int32 input_len, uint8** output, int32* output_len, MR_PLAT_EX_CB* cb )
```

## 说明

创建平台的电话本浏览对像。

## 参数

| 参数 | 说明 |
|---|---|
| input | 无 |
| input_len | 无 |
| output | 无 |
| output_len | 无 |
| cb | 无 |

## 返回值

MR_SUCCESS ：创建浏览对象成功
MR_FAILED ：创建浏览对象失败
MR_IGNORE
：不支持该功能
