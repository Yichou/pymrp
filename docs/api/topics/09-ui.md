#### `mr_menuSetItem`

```c

```
**说明** 设置菜单项。

**备注** 在菜单里设置一个菜单项，参数index是该菜单项的序号，当用户选中某个菜单项时，把index号通过mr_event函数发送到SkyEngine中。
[全文](mr_menuSetItem.md)

#### `mr_menuShow`

```c
int32 mr_menuShow(int32 menu)
```
**说明** 显示菜单。
**参数** menu 菜单句柄
**返回** 成功启动返回MR_SUCCESS,失败返回MR_FAILED.
**备注** 显示菜单。当菜单显示时，如果用户选择了菜单上的某一项，系统将构造SkyEngine消息，通过mr_event函数传送给SkyEngine，消息类型为MR_MENU_SELECT，参数为该菜单项的index。如果用户选择了退出该菜单，系统将构造SkyEngine消息，通过mr_event函数传送给SkyEngine，消息类型为MR_MENU_RETURN。


#### `mr_textCreate`

```c
int32 mr_textCreate(const char * title, const char * text, int32 type)
```
**说明** 建立文本框。
**参数** title 文本框的标题，unicode编码，网络字节序。; text 文本框内容，unicode编码，网络字节序。; type “取消”键。
**返回** &gt;0 为对话框句柄，MR_FAILED表示失败.
**备注** 创建一个文本框，并返回文本框句柄。文本框用来显示只读的文字信息。文本框和对话框并没有本质的区别，仅仅是显示方式上的不同，在使用上它们的主要区别是：对话框的内容一般较短，文本框的内容一般较长，对话框一般实现为弹出式的窗口，文本框一般实现为全屏式的窗口。也可以将对话框和文本框用相同方式实现。 文本框和对话框的消息参数是一样的。当文本框显示时，如果用户选择了文本框上的某个键，系统将构造SkyEngine消息，通过mr_event函数传送给SkyEngine，消息类型为MR_DIALOG_EVENT，参数为该按键的ID。“确定”键ID为：MR_DIALOG_KEY_OK；“取消”键ID为：MR_DIALOG_KEY_CANCEL。
[全文](mr_textCreate.md)
