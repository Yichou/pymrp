# mr_plat(4006) - 获取动感芯片上送的数值的范围值

```c
int32 mr_plat(int32 code = 4006, int32 param)
```

## 说明

获取动感芯片上送的数值的范围值 。

## 参数

| 参数 | 说明 |
|---|---|
| param | 无 |

## 返回值

&gt;1000 成功 返回值A那么动感芯片上送的值的范围在（-（A-1000）到（A-1000））
MR_FAILED
失败
MR_IGONRE
不支持该功能
注：以上动感芯片x,y,z坐标做如下定义：
1、 当手机平放的时候，Z方向正值最大。
2、 当手机平盖的时候，Z方向负值最大
3、 当手机屏幕向左，横立起来的时候，X方向正值最大；
4、 当手机屏幕向右，横立起来的时候，X方向负值最大；
5、 当屏幕对着自己的时候，竖立起来的时候，Y方向负值最大；
6、 当屏幕背向着自己的时候，竖立起来的时候，Y方向正值最大
