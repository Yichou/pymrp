## 2. 手册解包方法（可复现）

CHM 是编译过的 HTML 帮助文件，直接 7-Zip 解开：

```bash
7z x "SKYENGINE+API+参考手册.chm" -o ref/sky/     # 得到 .htm + 资源
python tools/extract_manual.py                     # GBK 解码 → 结构化文本 → docs/api/
```

要点：

- 原文编码 **GBK**（不是 UTF-8），解码时 `errors='replace'` 容错；
- HTML 表格被压扁后单元格用 `|` 结尾，解析器按此还原参数表；
- 306 页里有 4 页是空壳（`$$unsavedpage` 等），实际有效 288 页；
- 手册版权标注 `2005-2010 SKY-MOBI`，目录结构暗示曾经有更多卷（socket/压缩等
  章节的 See Also 指向不存在的页面）——**我们拿到的是残卷**。

## 3. 开源模拟器谱系

| 项目 | 年代 | 技术路线 | 现状 |
|---|---|---|---|
| SkyEngine 官方 VM | ~2003–2011 | 各平台原生移植（MTK/展讯/ADI…） | 消失，无公开副本 |
| **vmrp** | 2021 | C + Unicorn，Windows | 活跃，发行包自带运行时与游戏 |
| mrpoid | ~2014–2018 | Android NDK，原版头文件随包 | 停更，源码靠镜像流转 |
| **PymRP（本项目）** | 2026 | Python + Unicorn + pygame | 见 [11 实现对照](11-pymrp实现对照.md) |

三者的关系：vmrp 证明了"Unicorn + 桥接槽位"路线可行；mrpoid 保存了最权威的头文件；
PymRP 在两者基础上补齐了文档化（本知识库）与可读实现。

## 4. 正在消失的东西

按紧迫度排序：

| 资产 | 状态 | 后果 |
|---|---|---|
| **官方编译器与打包工具** | 已失传 | 无法从源码产出新 `.mrp`，生态不可再生 |
| 完整版手册 | 疑似残卷 | 部分接口只有名字没有参数（如 `MRAPP_IMAGE_DECODE_T` 字段） |
| 斯凯服务端 | 已关闭 | 联网类应用（QQ、天气、下载）永久失效 |
| 源码级 MRP 应用 | 极少流传 | 只能改资源，改不了逻辑 |
| 老 MRP 文件本身 | 网盘腐烂中 | 链接失效即永久丢失 |

## 5. 还能抢救什么、怎么抢救

1. **归档二进制**：`.mrp` 合集、`cfunction.ext`、字库，按包名+版本归档。
   二进制是"最后的事实"，任何文档写错它都能纠错；
2. **归档头文件**：`mrporting.h` / `dsm.h` / `vmrp.h` 的每一个版本变体。
   常量表失传一份，后人就要重踩一次我们踩过的坑；
3. **记录实测行为**：像 [03 包格式](03-MRP包格式规范.md)那样用"实测+验证闭环"的
   方式写文档，而不是凭印象转述；
4. **保持可运行**：模拟器是活的博物馆。文档会过时，能跑的模拟器不会。

## 6. 本仓库的资料边界（诚实声明）

- 手册是残卷，接口签名以"手册 + 头文件 + 实测"三方交叉，**冲突时以实测为准**；
- 键值/事件/声音枚举以 mrpoid 原版 `mrporting.h` 为最高权威（它看起来出自真机源码）；
- 包格式只验证了 2 个样本（dsm_gm / box），**未确证字段在 [03 §7](03-MRP包格式规范.md#7-未解之谜欢迎补充)**
  中明示，请勿当作已证明的事实传播；
- 历史背景（装机量、生态版图）是 D 级印象叙述，未做考据学验证。
