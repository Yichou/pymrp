## 各子系统的最小可用集

### 文件系统（03）

```
mr_open → mr_read/mr_write → mr_seek → mr_close
mr_getLen / mr_ferrno
mr_findStart → mr_findGetNext* → mr_findStop     目录枚举
mr_mkDir / mr_rmDir / mr_remove / mr_rename
```

坑：`mr_open` 的 `mode` 是位或组合（`MR_FILE_RDONLY=1, WRONLY=2, RDWR=4,
CREATE=0x10?...`），具体位值以手册 `api/mr_open.md` 为准；路径一律**相对**，
可能是 `a:/`、`c:/`、`fs:/` 前缀或裸相对路径，移植层都要容错。

### 图形（04）

```
mr_getScreenInfo      先查分辨率
mr_drawBitmap         唯一的位图绘制原语
mr_getCharBitmap      取字模（应用自绘文字时用）
mr_winCreate/Release  窗口句柄管理
```

图层/解码/DMA 都是 `mr_plat(Ex)` 扩展，普通应用不依赖 → 见 [06 专题](06-图形与图层专题.md)。

### 声音（05）

```
一次性:  mr_playSound(type, data, len, loop) / mr_stopSound(type)
流媒体:  mr_platEx(201x..216x) 状态机
PCM 直写: mr_plat(102/103) 环形缓冲
```

→ 详细见 [05 声音与流媒体专题](05-声音与流媒体专题.md)。

### 网络（07）

```
mr_initNetwork → mr_socket → mr_connect → mr_send/mr_recv → mr_closeSocket
mr_getHostByName      DNS（MR_WAITING 异步）
mr_connectWAP         走 WAP 网关的连接
```

不联网的应用不会碰这些；实现模拟器时可以全部返回 `MR_FAILED` 不崩溃。

### 事件与生命周期（10）

```
mr_event(code, p0, p1)        一切输入的入口
mr_timerStart/Stop            应用级节拍
mr_pauseApp / mr_resumeApp    前后台切换
mr_start_dsm[B/C/_ex]         子应用加载（启动器 → 游戏）
```

### UI 控件（09）

菜单/编辑框/文本框/对话框四族，Create/Refresh/Release 三段式。
实现模拟器时可以用最简实现（画个列表框），因为**应用通常会自己画 UI**，
原生控件多用于输入法、系统弹窗这类场景。

## 实现优先级建议（D 级，来自实测经验）

按"不做就跑不起来"排序：

1. **P0（不实现必崩）**：内存、文件、时间、事件/定时器、`mr_drawBitmap`、屏幕信息
2. **P1（多数应用要）**：按键事件、`mr_getCharBitmap`、随机数、系统信息、声音播放
3. **P2（部分应用要）**：网络、UI 控件、图层、图片解码、流媒体
4. **P3（可忽略）**：相机、录音、电话本、短信、天气、NES、QQ

P3 的统一兜底策略：**`mr_plat`/`mr_platEx` 未识别的 code 返回 `MR_IGNORE`**，
不要返回 `MR_FAILED`（应用对失败的反应可能是退出，对 IGNORE 的反应是降级）。
